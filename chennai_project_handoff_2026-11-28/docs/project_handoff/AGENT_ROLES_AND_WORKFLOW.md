# Agent Roles and Workflow

## Pro agent — execution lead

Responsible for:
- Baseline inventory and protection.
- Code and pipeline inspection.
- Source reconciliation tooling.
- Scientific integration assessment.
- Controlled experiments and validation comparisons.
- ML/statistical reproducibility.
- Tests and technical documentation.
- Manuscript corrections after evidence review.
- Versioned output packaging and handoff.

## Agent 1 — independent reviewer

Responsible for:
- Independent literature review.
- DOI, authorship, venue and citation verification.
- Dataset/source authenticity and provenance.
- Independent evidence classification.
- Review of scientific claims.
- Methodological and statistical assessment.
- Novelty assessment.
- Manuscript review and written dissent where appropriate.

Agent 1 must not merely repeat the Pro agent's conclusions. Provide the actual evidence and code required for independent assessment.

## Required review loop

1. Pro agent inventories and prepares evidence.
2. Agent 1 independently reviews it.
3. Pro agent responds point-by-point.
4. Disagreements are recorded.
5. Decisions are made with evidence and rationale.
6. User/supervisor approval is requested for decisions that affect research scope, claims, authorship, submission or release.

## Decision gates

- Gate 0: baseline protected.
- Gate 1: citation and evidence audit complete before manuscript claim revision.
- Gate 2: DEP2–SUS1 integration justified before numerical combination.
- Gate 3: validation protocol and independent data verified before metrics are reported.
- Gate 4: ML interpretation checked before paper revision.
- Gate 5: supervisor and venue review materials prepared.
- Gate 6: Agent 1 final manuscript review complete before submission-readiness declaration.

## Reporting cadence

At each milestone report:
- Completed.
- Attempted.
- Blocked.
- Agent 1 review pending.
- User/supervisor decision needed.
- Files created/modified.
- Commands and tests actually run.
- Next milestone.

Never claim a command ran unless there is execution evidence.
