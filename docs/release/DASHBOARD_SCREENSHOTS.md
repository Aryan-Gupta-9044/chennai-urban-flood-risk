## Captioning and publication

Before reusing a screenshot in a report or paper:
- Confirm its source package/version and capture context.
- Add a descriptive caption explaining what is shown.
- Avoid implying that a screenshot validates the underlying layer.
- Remove or mask any local paths, tokens or personal information if present.
- Prefer fresh captures for claims about the current dashboard build.
